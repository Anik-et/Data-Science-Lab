| Question                                         | Test                 | Example                       |
| ------------------------------------------------ | -------------------- | ----------------------------- |
| Compare means of 2 normal groups                 | t-test               | Male vs Female income         |
| Compare 2 non-normal groups                      | **Mann–Whitney U**   | Fraud vs Non-fraud amount     |
| Compare 3+ groups                                | ANOVA                | Revenue across 5 regions      |
| Relationship between categorical variables       | Chi-Square           | Payment Method vs Fraud       |
| Linear relationship between continuous variables | Pearson Correlation  | Age vs Income                 |
| Monotonic relationship                           | Spearman Correlation | Rank vs Salary                |
| Compare proportions                              | Z-test / Chi-Square  | Conversion rate A/B test      |
| Is a feature normally distributed?               | Shapiro-Wilk         | Before using parametric tests |
